# Chunk B15a: market index entries carry `provides` and `requires` (concept keys); lookups `providersOf` and `requirersOf`

Prototype. Synthetic data only. Not for clinical use. Repo: CCIS. Needs: B15 (DONE). Decisions: ED-5, ED-12, ED-52 (new, OPEN working choice). Before B15b and C15.

## What exists
`ccis-market.js`: `ENTRY_MEMBERS` (line 268) is a closed list of 12; `loadMarket` (line 270) refuses an entry with any other member set (M-001), then checks every stored file against its entry (M-010). `publishArtefact` builds the entry at about line 190. `conceptOwners` (already imported) reads the highest version of each element and lists owners and users per concept. `market/index.json` is generated by `scripts/market-build.js` (`--check` compares). Tests pin the 12 members at `test/ccis-market.test.js` line 109.

## Decision (ED-52, change before the build)
Optional members, not `ccis-market/2`. The format string stays `ccis-market/1`. An entry has the 12 members plus `provides` and `requires`, both present or both absent. `publishArtefact` always writes both. A market with no such members (older index text) still loads and its entries are "not declared": lookups skip them. When both are present, `loadMarket` recomputes them from the stored file and refuses a mismatch as M-010. Reason: additive, no new format string for the app, Marketplace CI and EMR to learn. A `/2` bump stays open if you prefer it.

## What to build (about 35 lines, all in `ccis-market.js`)
- `conceptsOf(doc)`, pure, returns `{ provides, requires }`, each a sorted list of concept codes, no duplicates:
  - `contextual-element`: `conceptOwners([doc])`: `provides` = concepts with an owner field, `requires` = concepts with only `ownedBy` fields.
  - `rule-pack`: `requires` = the input concepts; `provides` = [].
  - `pathway`, `analytics-package`: both [] (a pathway's elements are already in `references`).
- Entry gains the two members; `loadMarket` accepts 12 or 14 members (the 12 required, the 2 optional and together), and checks the derived lists.
- `providersOf({ market, concept })` and `requirersOf({ market, concept })`: entries of the highest version of each id, as `{ id, type, version }`, sorted; unknown or non-string concept gives `[]`; refusal M-001 on a bad market. They return ids only.
- Then run `node scripts/market-build.js` to regenerate `market/` and `node scripts/build-app.js` for `index.html`.
